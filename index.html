YouTube Audience Reception Analysis

An AI-powered academic project for understanding how audiences react to movies and trailers through YouTube comments.

About the Project

```

YouTube Audience Reception Analysis is a data science and natural language processing project that analyzes audience reactions to movie and trailer content on YouTube.

The system processes audience comments and uses sentiment analysis, emotion detection and topic modeling to identify patterns in public opinion and audience engagement.

```

What We Analyze

```

Sentiment

Identify whether audience comments express positive, negative or neutral sentiment.

Emotions

Explore emotional reactions expressed by viewers in their comments.

Topics

Discover recurring discussion topics and themes within audience comments.

Engagement

Analyze audience engagement patterns using available YouTube interaction data.

```

Technology

``` Python Pandas Natural Language Processing VADER Transformers Topic Modeling YouTube Data API Streamlit Machine Learning ```

Project Workflow

```

YouTube Data → Comment Collection → Data Cleaning → Sentiment Analysis → Emotion Detection → Topic Analysis → Engagement Analysis → Interactive Dashboard

```

Objective

```

The objective is to build an academic prototype that can transform large amounts of unstructured YouTube audience feedback into understandable insights about audience reception.
```
